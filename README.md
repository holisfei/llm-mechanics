# 简介

这个项目主要是通过一系列的实验去理解LLM大模型在底层的运行机制。从而能够理解大模型背后到底在做些什么。

这里使用的是```GLM```的```glm-4.5-air```模型做的验证实验。

每个问题都有对应的代码实验去辅助理解背后的本质，总共分为6个大模块：

1. ```token```到底是什么？为什么中文的```token```成本高
    - ```Tokenizer```分词器
    - ```BPE```分词算法
2. 模型生成回复的本质是什么?模型是怎么训练的？
    - 预测下一个```token``` + 自回归
    - 从```base```模型到```chat```模型
3. 参数调整对模型的影响
    - ```temperature```
    - ```do_sample```
    - ```top-p```
    - ```top-k```
4. 上下文窗口的限制和管理
    - 上下文窗口的计算
    - 模型本身没有记忆，全靠喂给模型历史
5. 模型会产生幻觉的本质
    - 模型只是在做预测，不做事实性的验证
    - 通过参数影响模型幻觉
    - 模型幻觉无法完全消除
6. ```Embedding```模型和```RAG```检索的原理
    - 文本向量化
    - 余弦相似度计算
    - ```RAG```检索原理

# 项目目录

```note```目录是每个模块的```markdown```详细笔记

```src```目录是每个模块的```python```验证代码

```notebook```目录是每个模块的```jupyter lab```可视化notebook

# 运行项目

需要提前配置环境变量```api key```，在根目录创建```.env```文件，且填入```ZAI_API_KEY=xxx```

运行依赖: ```uv sync```

启动```jupyter```: ```uv run jupyter lab```
